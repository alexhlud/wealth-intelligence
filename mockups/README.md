# Observatory mockups

These static HTML files are design references for the **The Observatory**
direction. The authenticated compositions demonstrate the proposed **Midnight
Scope** variant: a warm, dark work field with centered top navigation rather
than a desktop sidebar. `typography-study.html` compares display-face options
in financial-screen context.

They are not application code, product routes, or production assets, and they
are intentionally kept at the repository root so Vite does not bundle them.

All names, accounts, prices, balances, performance figures, and dates shown
here are fictional and illustrative.
